## About the Project

This project is a security review of a fictional software company called **CloudDesk Technologies**.

The goal was to check how well the company protects its systems, users, and customer data.

I reviewed the current security practices, identified areas that need improvement, assessed the possible risks, and created action items to address them.

> This is a fictional project created for learning and portfolio purposes.

## What I Checked

- How users log in and access the system
- Whether important accounts have extra security
- How employee access is given and removed
- How customer data is protected
- How security problems are detected
- How software weaknesses are handled
- Whether backups can be recovered
- How security incidents are handled
- How third-party companies are reviewed

## What I Created

### Security Review

Recorded what security measures are currently in place and where improvements are needed.

### Risk Assessment

Listed the main risks and rated them based on how likely they are and how much damage they could cause.

### Access Review

Checked how employee and administrator access is given, reviewed, and removed.

### Data Protection Review

Checked how customer information is stored, protected, retained, and deleted.

### Vendor Review

Reviewed the security risks related to companies that provide services to the business.

### Remediation Tracker

Created a list of actions needed to fix the identified problems, including:

- What needs to be fixed
- Who is responsible
- Priority
- Current status
- Target date

### Management Summary

Created a simple summary of the main problems and the areas that should be addressed first.

## Main Findings

The review identified areas such as:

- Extra login security was not enabled for everyone
- User access reviews were not consistently documented
- Employee access removal needed better tracking
- Customer data classification needed improvement
- Security monitoring needed better coverage
- Software security issues needed clearer deadlines
- Backup recovery testing needed better documentation
- Third-party security reviews needed regular updates
