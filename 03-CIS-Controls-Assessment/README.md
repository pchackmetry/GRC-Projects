# Project 03 — CIS Controls Assessment

🔗 **[View Live Notion Project](https://tidal-selenium-6c0.notion.site/03-CIS-Controls-Assessment-3c20f571c65481ac80b4c85a30724694)**

## Overview

A mock CIS Controls assessment conducted for **CloudServe Technologies**, a fictional SaaS organization.

The assessment evaluates selected CIS Controls and identifies control implementation gaps, evidence requirements, risks, and remediation actions.

> **Disclaimer:** This is a fictional assessment created for learning and portfolio purposes. It is not an actual security audit, certification, or attestation.

## Objectives

- Assess selected CIS Controls
- Evaluate control implementation status
- Identify security and compliance gaps
- Define required evidence
- Assess and prioritize risks
- Recommend remediation actions
- Assign control ownership
- Prepare management-level reporting

## Assessment Areas

The assessment covers selected controls related to:

- Enterprise asset management
- Software asset management
- Data protection
- Secure configuration
- Account management
- Access control
- Vulnerability management
- Audit log management
- Data recovery
- Incident response
- Security awareness
- Network infrastructure management

## Project Deliverables

### 1. CIS Controls Matrix

The control matrix documents:

- Control ID
- CIS Control
- Safeguard
- Implementation status
- Required evidence
- Identified gap
- Risk
- Priority
- Recommendation
- Control owner

### 2. Evidence Tracker

Tracks evidence required to validate control implementation, including:

- Policies
- Procedures
- Reports
- Logs
- Records
- Screenshots

Each evidence item is assigned an owner and review status.

### 3. Gap Assessment

Documents identified control weaknesses and evaluates:

- Finding
- Related control
- Gap
- Risk
- Business/security impact
- Recommendation
- Owner
- Priority
- Remediation status

### 4. Remediation Tracker

Tracks corrective actions resulting from identified gaps.

Key fields include:

- Remediation ID
- Finding ID
- Control
- Remediation action
- Owner
- Priority
- Status
- Target date
- Notes

### 5. Management Summary

Provides an executive-level summary of:

- Assessment results
- High-priority risk areas
- Medium-priority risk areas
- Recommended actions
- Overall control maturity observations

### 6. Assessment Dashboard

Provides a consolidated view of:

- Controls assessed
- High-priority gaps
- Medium-priority gaps
- Remediation actions
- High-risk areas
- Control status
- Evidence status
- Remediation status

## Key Risk Areas

### High Priority

- Enterprise asset inventory
- Data classification
- Account management
- Access control
- Vulnerability management
- Centralized logging
- Data recovery

### Medium Priority

- Secure configuration baselines
- Incident response exercises
- Network infrastructure documentation

## Recommended Actions

1. Establish centralized asset inventory and ownership.
2. Standardize account and access review processes.
3. Implement formal data classification requirements.
4. Define vulnerability remediation SLAs.
5. Expand centralized security logging.
6. Perform periodic backup restoration testing.
7. Establish secure configuration baselines.
8. Conduct regular incident response exercises.
9. Maintain accurate network infrastructure documentation.
